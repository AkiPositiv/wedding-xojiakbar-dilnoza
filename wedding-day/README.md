# Wedding Day — приглашение с занавесом из флагов

Основное приглашение Хожиакбара и Дилнозы: https://akipositiv.github.io/wedding-xojiakbar-dilnoza/

- Три языка: uz / kk / ru.
- Музыка с кнопкой «Музыка» для включения и выключения.
- Анкета: ответы приходят в Google Таблицу и уведомлением в Telegram (настройка — в [google-apps-script/НАСТРОЙКА.md](google-apps-script/НАСТРОЙКА.md)).
- Карты для подарков: номер копируется по нажатию.

## Что на странице

| Блок | Фон | Анимация |
|---|---|---|
| Вход | Занавес: слева флаг Узбекистана, справа флаг Казахстана (WebGL) | Ткань колышется от ветра. По касанию половины расходятся и собираются у краёв, сверху сыплется шашу — монеты и сладости |
| Первый экран | Ханатлас во весь экран (WebGL) | Волны ветра под шёлком, блики. Бархатная арка-портал прорисовывается золотом, имена выводятся пером |
| Обращение | Ганч — белый резной алебастр со звёздами-хатам | По рельефу медленно проходит солнечный блик |
| Когда | Самаркандская майолика: лазурит и бирюза | Блик по глазури. День свадьбы обводится восьмиконечной звездой, цифры отсчёта прокручиваются |
| Программа | Вечер над степью: от золотого часа к ночи, юрта, купол и минарет | Солнце садится при прокрутке, выходят луна и мерцающие звёзды, в окнах горит свет |
| Место | Лён и сюзане | Розетка сюзане «вышивается» стежками на глазах |
| Пожелания | Красная казахская кошма | Кайма из «қошқар мүйіз» прорисовывается от центра к краям |
| Анкета | Лён | После отправки — дождь шашу |
| Контакты и финал | Атлас и бархатная арка | Атлас медленно плывёт, по нему пробегают волны |

**Разделители** чередуются двух видов:
- атласная лента, по которой бежит волна;
- золотой орнамент «қошқар мүйіз» с медальоном, по нему пробегает блик.

## Файлы

```
index.html          разметка
css/style.css       оформление блоков и анимации
js/config.js        данные (имена, дата, место, программа, контакты) на трёх языках
js/i18n.js          тексты интерфейса
js/textiles.js      узоры кодом: ханатлас с эффектом иката, флаги, орнамент, ганч, майолика
js/weave.js         WebGL-шейдеры занавеса и атласа
js/main.js          логика страницы
assets/music/       музыка
```

Все узоры рисуются кодом, без картинок. Если у гостя нет WebGL, вместо него показывается простой вариант на CSS. Если в системе включено «уменьшение движения», анимации отключаются.
