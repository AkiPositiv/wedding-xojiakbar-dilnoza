# Приглашение на свадьбу Хожиакбара и Дилнозы

Одностраничный сайт-приглашение на трёх языках: русском, узбекском (латиница) и казахском.

Как это выглядит для гостя:
- он открывает конверт с сургучной печатью, печать раскалывается, и начинает играть «Hijo de la luna»;
- письмо разворачивается в страницу, на которой проступают имена в золотом венке;
- при прокрутке фон переходит от дня к вечеру вместе с программой.

Работает без сборки: обычные HTML, CSS и JS.

## Структура

```
index.html                 разметка (тексты подставляются из словаря)
css/style.css              оформление и анимации
js/config.js               ДАННЫЕ: имена, дата, место, программа, контакты — на трёх языках
js/i18n.js                 тексты интерфейса на ru / uz / kk
js/main.js                 логика (конверт, музыка, отсчёт, анкета, языки)
assets/music/              музыка
assets/photos/             сюда будут фотографии
google-apps-script/Code.gs приём ответов анкеты в Google Таблицу
```

## Языки

- Переключатель **Рус / Oʻzb / Қаз** находится в правом верхнем углу. Выбор запоминается в браузере гостя.
- Если гость ещё ничего не выбирал, язык берётся из настроек его телефона. Для всех остальных языков открывается русский.
- Ссылка сразу на нужный язык: `?lang=uz`, `?lang=kk` или `?lang=ru`.
- Данные (имена, место, программа) задаются в `js/config.js` в виде `{ ru: "…", uz: "…", kk: "…" }`. Тексты интерфейса лежат в `js/i18n.js`.
- Ответы анкеты всегда приходят в таблицу на русском, плюс отдельная колонка «Язык».

## Музыка

Трек лежит в `assets/music/` и играет по кругу. Путь к нему указан в `music` в `js/config.js`. Внизу справа есть кнопка со значком динамика, она выключает и включает звук.

## Личное обращение

```
https://…/?g=Анна и Игорь
```

Вместо общего обращения будет «Дорогие Анна и Игорь!» (на узбекском «Hurmatli …!», на казахском «Құрметті …!»). Имя также подставится в анкету. Параметры можно совмещать: `?lang=uz&g=Anna`.

## Добавить в календарь

Кнопка открывает Google Календарь с уже заполненным событием: название, 26 ноября 17:30 по Ташкенту, место. Гостю остаётся нажать «Сохранить».

## День → вечер

При прокрутке программы фон меняется вслед за временем каждого пункта: до 17:00 — день, с 17:00 — золотой час, с 20:00 — закат, с 22:00 — вечер. После программы фон возвращается к дневному.

## Анкета гостя → Google Таблица

1. Создайте Google Таблицу и откройте в ней **Расширения → Apps Script**.
2. Вставьте код из `google-apps-script/Code.gs` и сохраните.
3. Нажмите **Развернуть → Новое развертывание**, выберите тип **Веб-приложение**:
   - «Запуск от имени»: **Я**
   - «У кого есть доступ»: **Все**
4. Скопируйте URL веб-приложения (заканчивается на `/exec`) и вставьте его в `rsvpEndpoint` в `js/config.js`.

Пока `rsvpEndpoint` пустой, анкета работает в демо-режиме и ничего никуда не отправляет.

## Публикация на GitHub Pages

1. Загрузите репозиторий на GitHub.
2. Откройте **Settings → Pages** и выберите **Deploy from a branch → main → / (root)**.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Чтобы посмотреть локально, откройте `index.html` в браузере. Чтобы проверить с телефона в той же сети, запустите `python -m http.server` в папке проекта.
